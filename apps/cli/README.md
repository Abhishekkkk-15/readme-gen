# cli

## Overview

The `cli` sub-project is a command-line interface application designed to provide a user-friendly interface for interacting with the `readme-gen-workspace` monorepo. Its primary role is to facilitate the generation of README files for individual projects within the workspace.

## Purpose

The `cli` application serves as a tool for developers to quickly generate high-quality README files for their projects. It automates the process of collecting project metadata and generating a well-structured README file, saving time and effort.

## Installation

To install the `cli` application, navigate to the `apps/cli` directory and run the following command:

```bash
cd apps/cli
pnpm install
```

## Running the Application

To start the `cli` application, run the following command:

```bash
cd apps/cli
pnpm run dev
```

This will start the application in development mode, allowing you to interact with it using the command-line interface.

## Core Dependencies

The `cli` application relies on the following core dependencies:

* `typescript` for type checking and compilation
* `eslint` for code linting and quality assurance
* `readme-gen-workspace` for accessing project metadata and generating README files

## Usage

To use the `cli` application, simply run the following command:

```bash
cd apps/cli
pnpm run dev
```

This will present you with a menu of options for generating README files. Follow the prompts to select the project you wish to generate a README file for, and the application will take care of the rest.
